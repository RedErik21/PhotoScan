PhotoScan

Metti ordine in anni di foto e video. PhotoScan trova i duplicati, riconosce cosa c'è in ogni foto e ti propone una struttura di cartelle per anno, mese ed evento. Tutto gira sul tuo PC: nessuna foto viene caricata online.

Come funziona

Quattro passi, sempre in ordine. Puoi fermarti e riprendere quando vuoi.

  1. Scegli l'archivioIndica la cartella delle foto originali. Viene solo letta.
  2. AnalisiPhotoScan legge data, GPS e contenuto di ogni file con un modello di IA eseguito sul tuo PC. È riprendibile: i file già analizzati non vengono rifatti.
  3. Controlla duplicati e cartelleRivedi le copie e l'anteprima della nuova struttura. Nulla è ancora cambiato.
  4. Crea le cartelleSolo dopo la tua conferma esplicita PhotoScan crea la nuova struttura, con collegamenti o copie.

I tuoi file al sicuro

La regola di base: PhotoScan non cancella mai nulla.

  • La cartella delle foto originali è sempre in sola lettura.
  • Tutto parte in simulazione: prima vedi il piano, poi decidi.
  • I duplicati vengono spostati in una cartella dedicata (_Duplicati), mai eliminati.
  • Nessun servizio online per le foto. L'unico collegamento a internet è il controllo degli aggiornamenti, disattivabile.
  • Ogni operazione di creazione lascia un registro nella cartella di destinazione.

Installazione (Windows)

Servono Python 3.13 e, consigliata, una scheda grafica NVIDIA. Senza NVIDIA funziona comunque, ma più lentamente.

cd PhotoScan                        # cartella estratta dal download
python -m venv .venv
.\.venv\Scripts\activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126   # GPU NVIDIA
pip install -r requirements.txt
winget install Gyan.FFmpeg          # facoltativo, per i video

Al primo utilizzo viene scaricato il modello di riconoscimento (circa 400 MB, una sola volta). Poi avvia PhotoScan con il comando .\.venv\Scripts\pythonw.exe -m fotoscan.desktop o dall'icona sul Desktop.

Domande frequenti

Le mie foto vengono inviate online?

No. Analisi, ricerca e organizzazione avvengono sul tuo computer. L'unica connessione è il controllo delle nuove versioni, che puoi disattivare.

Cancella le mie foto?

No. Le originali sono in sola lettura e i duplicati vengono spostati, non eliminati. Decidi tu cosa tenere.

Quanto spazio occupa?

Oltre allo spazio del programma e del modello di riconoscimento, il catalogo e la cache crescono con il numero di file. Il progetto è pensato per archivi di circa 200 GB e 14.000 file.

Posso interrompere l'analisi?

Sì. Chiudendo l'app si ferma e alla riapertura riprende dai file non ancora elaborati.

Quali formati supporta?

Foto JPEG, PNG, HEIC (con il supporto incluso) e video. I video richiedono FFmpeg. HEIC e TIFF nel browser sono mostrati in versione JPEG generata dal programma.

Come aggiorno PhotoScan?

Le nuove versioni si trovano nelle Release di GitHub e nelle Impostazioni dell'app. L'aggiornamento si installa alla riapertura, con copia di riserva.

Il riconoscimento dei volti è obbligatorio?

No. È disattivato di default e si attiva dalle Impostazioni.
